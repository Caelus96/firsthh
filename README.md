# 作业文件批量整理小脚本
一个用来批量整理作业文件的小工具：扫描文件、批量改名、按类别归档，还能生成整理报告和一键撤销。

## 功能一览

| 功能 | 说明 | 实现版本 |
| --- | --- | --- |
| 扫描列表 | 列出目录下所有文件，显示大小、修改时间，可按扩展名过滤 | organizer-v1.py |
| 批量改名 | 把 `学号_姓名_作业名.pdf` 改成 `作业名_学号.pdf`，先打印确认再改，重名不覆盖 | organizer-v2.py |
| 归档 + 报告 + 撤销 | 按学期/类别归档，生成整理报告（处理数/跳过数/原因），支持撤销上次操作 | organizer-v3.py |

## 快速上手

```bash
# 1. 扫描并列出文件
python organizer-v3.py scan ./demo

# 2. 批量改名（先预览，确认后执行）
python organizer-v3.py rename ./demo

# 3. 按类别归档
python organizer-v3.py archive ./demo

# 4. 撤销上一次操作
python organizer-v3.py undo ./demo
```
## 安全设计

| 风险 | 处理方式 |
| --- | --- |
| 重名文件被覆盖 | 目标已存在则跳过，并给出原因 |
| 仅大小写不同的重名（Windows） | 大小写不敏感检查，跳过并说明 |
| 某个文件操作失败 | 单文件失败不影响整批，其余继续处理 |
| 改错了想反悔 | `undo` 命令读取日志，一键撤销上次操作 |
